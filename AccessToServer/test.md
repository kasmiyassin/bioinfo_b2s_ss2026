# How to: Install MobaXterm (Windows)

MobaXterm is a free terminal application for Windows that allows you to connect to remote Linux servers via SSH. Follow the steps below to download and install it.

---

### Step 1: Check your internet connection

Make sure your computer is connected to the internet before starting the download.

---

### Step 2: Download MobaXterm

Go to the official download page:
👉 [https://mobaxterm.mobatek.net/download.html](https://mobaxterm.mobatek.net/download.html)

Click **"Download now"** under the **Home Edition (Free)**.

<img src="/AccessToServer/docs/assets/CISWork1.png" alt="Download Home Edition" width="600">

On the next page, click the green button showing the latest version of **MobaXterm Home Edition** to download the installer zip file.

<img src="/AccessToServer/docs/assets/CISWork2.png" alt="Download the installer file" width="600">

> ⚠️ If you are using a computer that is not your personal device, administrator privileges may be required to complete the installation.

---

### Step 3: Extract and run the installer

A zip file named something like `MobaXterm_Installer_vXX.X` will appear in your Downloads folder.

<img src="/AccessToServer/docs/assets/CISWork3.png" alt="Zip file" width="600">

1. **Right-click** the zip file and select **Extract All...**

<img src="/AccessToServer/docs/assets/CISWork4.png" alt="Extract files" width="600">

2. Choose a destination folder (the default is fine) and click **OK**.

<img src="/AccessToServer/docs/assets/CISWork5.png" alt="Folder appears" width="600">

3. Open the extracted folder — you will see two files inside.
4. **Double-click** the file named `MobaXterm_installer_XX.X` to launch the setup wizard.

<img src="/AccessToServer/docs/assets/CISWork6.png" alt="Launch the installer" width="600">

> If a Windows security warning appears asking whether to run the file, click **Yes**.

---

### Step 4: Complete the installation

The MobaXterm Setup Wizard will open:

<img src="/AccessToServer/docs/assets/CISWork7.png" alt="Setup Wizard" width="600">

1. Click **Next**.
2. Read and accept the **User Agreement**, then click **Next**.
3. Confirm the installation destination folder (the default is recommended) and click **Next**.
4. Click **Install** to begin the installation.

<img src="/AccessToServer/docs/assets/CISWork8.png" alt="Installing MobaXterm" width="600">

---

### Step 5: Launch MobaXterm

Once installation is complete, MobaXterm is ready to use.

To make it easier to find in the future, create a desktop shortcut:

1. Locate the MobaXterm icon (e.g. in your Downloads or installation folder).
2. **Right-click** the icon → **Send to** → **Desktop (create shortcut)**.

<img src="/AccessToServer/docs/assets/CISWork9.png" alt="Create a shortcut" width="600">

You can now open MobaXterm directly from your desktop and use it to connect to the course server via SSH.

<img src="/AccessToServer/docs/assets/CISWork10.png" alt="MobaXterm homescreen" width="600">

For further guidance on using MobaXterm, refer to the official [MobaXterm documentation](https://mobaxterm.mobatek.net/documentation.html#1).
