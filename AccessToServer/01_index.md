# Home

## Steps to Begin

In this course, you are provided accounts on the TIFI servers. Both servers run **Linux Ubuntu 24.04** and provide a common programming environment for all students.

**To complete a practical assignment on the server, you typically need to go through the following steps:**

1. From your local computer (your laptop or lab computer), log on to the server using either [Windows](remoteLoginMobaXtermWindows.md) or [Mac](logOnToServerMac.md).
2. While logged on to the server, use a terminal text editor (e.g., [nano](introductionNano.md), [emacs](introductionEmacs.md), or [vi](introductionVi.md)) to write, revise, and test your scripts until they run without errors.
3. Use **Git** to version-control your work and push your results to GitHub for submission and collaboration.

If you have any questions or notice any mistakes in these tutorials, please contact your instructor via email.
