Ce dossier contient toutes les informations nécessaires pour accéder au cluster de calcul (HPC) et aux jeux de données.
Il comprend les documents suivants :

- Guide de connexion : Procédure pas à pas pour se connecter au serveur via SSH.

- Logiciels requis : Liens et instructions pour l'installation de WinSCP, MobaXterm ou FileZilla.

- Gestion des accès : Procédure d'installation de la clé publique pour une connexion sécurisée sans mot de passe.
