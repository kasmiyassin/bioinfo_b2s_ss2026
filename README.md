Ce dossier regroupe le matériel pédagogique nécessaire à la prise en main de l'environnement Linux (Ubuntu).

Objectif : Apprendre à naviguer dans l'arborescence du système, utiliser la ligne de commande (Shell) et comprendre l'architecture du HPC (ordonnanceur SLURM).

Contenu : Aide-mémoire des commandes de base (ls, cd, grep, awk) et introduction au workflow Git.
