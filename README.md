Dossier Session_02 : Contrôle Qualité (QC) des données NGS
Ce dossier est dédié à l'évaluation de la fiabilité des données brutes.

- Problématique : Identifier si un échantillon est exploitable ou s'il présente des biais techniques.
- Outils : Utilisation de FastQC pour le diagnostic et MultiQC pour l'agrégation des rapports de qualité.
- Nettoyage : Nettoyage des séquences (trimming) avec Trimmomatic ou fastp.
